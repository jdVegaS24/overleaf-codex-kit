# Prompt para instalar la skill sin terminal

Usa este prompt en Codex desde la carpeta del repositorio `overleaf-codex-kit`:

```text
Instala la skill `overleaf-paper-sync` en mi instalacion local de Codex para que quede disponible en cualquier proyecto. Copia la carpeta `skills/overleaf-paper-sync` a `~/.codex/skills` o a `$CODEX_HOME/skills`, conserva `SKILL.md`, `agents/openai.yaml`, `references/` y `scripts/`, y confirma al final la ruta donde quedo instalada.
```
